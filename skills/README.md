# Skills

Agent skills that maintain this knowledge base. Each skill is a folder with a
`SKILL.md` (the instructions) and optional `scripts/`.

Skills are tooling, not knowledge. The gate in
[kb-add-topic/scripts/check_kb.py](kb-add-topic/scripts/check_kb.py) checks their
links, frontmatter, and leaks.

## Index

- [kb-add-topic](kb-add-topic/SKILL.md) — Sort new material into the KB, keep only general lessons, run the gate, and commit.
